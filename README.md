# 🐾 Aura Pet Shop - Website & Agendamento Interativo

Este é um projeto moderno de **Pet Shop** projetado com foco em excelente experiência de usuário (UX/UI), design limpo, tipografia amigável e conversão. Criado originalmente para demonstrar práticas de desenvolvimento frontend premium com Next.js, Tailwind CSS e TypeScript.

Livre para uso, estudos, modificação e inclusão em seu portfólio pessoal! 🚀

---

## ✨ Funcionalidades Principais

- 🐕 **Identidade Visual Vibrante:** Paleta de cores moderna em tons claros, laranja amigável (`brand`) e detalhes azuis (`accent-blue`).
- 📱 **Design Totalmente Responsivo:** Layout fluido e otimizado para celulares, tablets e computadores.
- ⚡ **Simulador de Agendamento Interativo:**
  - Seleção dinâmica de espécie (Cão/Gato) e porte (Pequeno/Médio/Grande).
  - Cálculo de preço em tempo real de acordo com o porte e serviços selecionados.
  - Seleção de múltiplos adicionais (Hidratação, Escovação de Dentes, Corte de Unhas).
  - Geração automática de link pré-formatado para envio de agendamento via **WhatsApp**.
- 🛠️ **Arquitetura Moderna:** Componentes modulares, hooks de efeitos visuais (`useScrollReveal`), e ótima estrutura para SEO.
- 💬 **Sessões Atraentes:**
  - Bento Grid de Serviços.
  - Sobre Nós (Filosofia amigável).
  - FAQ com Accordion interativo.
  - Depoimentos reais de tutores de pets.

---

## 🛠️ Tecnologias Utilizadas

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Estilização:** [Tailwind CSS v4](https://tailwindcss.com/) & CSS Variables
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Ícones:** [Lucide React](https://lucide.dev/)
- **Animações:** Efeitos de revelação suaves baseados em Intersection Observer API

## 🚀 Como Executar Localmente

### 1. Clonar o repositório
```bash
git clone https://github.com/clouddepaula-rgb/petshop.git
cd petshop
```

### 2. Instalar dependências
```bash
npm install
```

### 3. Rodar o servidor de desenvolvimento
```bash
npm run dev
```
Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.

### 4. Build de produção
```bash
npm run build
```
